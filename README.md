# Navia – eine Datei

1. `index.html` bei GitHub ins Repo legen (Hauptordner).
2. Optional daneben: `apple-touch-icon.png` (App-Icon auf dem iPhone).
3. Settings → Pages → Deploy from a branch → main / root.
4. Die **github.io**-Adresse in Safari öffnen → Teilen → Zum Home-Bildschirm.

Keine Unterordner, keine weiteren Dateien nötig.
